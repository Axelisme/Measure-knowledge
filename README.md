# 量測知識庫

這個獨立 Git repo 保存可重用的量測判斷方法。從 [routing](routing.md) 尋找 domain，也可以直接瀏覽檔案或以關鍵字搜尋。

## 內容

每條經驗是一個資料夾，以 README.md 為入口，可包含說明、案例、圖片與離線分析腳本。從未驗證設定開始時，可先讀 [coherence 決策流程](experiences/coherence-bringup/README.md)，再依問題進入其他條目。

經驗說明處理的判斷問題、適用條件、依據與限制。可以包含正常表現、物理圖像、品質判斷、辨別實驗及成本取捨。分開記錄觀察、假說與已驗證內容。

圖像附來源與判讀重點，不只保留 session 暫存路徑。正式量測資料留在原本的 artifact 儲存位置，這裡保存引用與必要的精選圖例。

## 維護

修訂前搜尋相同問題，保留仍有用的反例與限制，更新相關 routing 入口。將一次有意義的知識修訂提交到本 repo；Git history 用來追溯與撤銷，不是日常必讀內容。

當次目標、policy 與進度留在量測任務紀錄。歷史經驗不能覆蓋當前使用者的目標、授權或安全限制。

模擬案例用來保存判斷方法與反例，不驗證真實硬體安全或校準效果。數值設定留在案例中；移轉時重新確認單位、功率、時序、phase convention 與適用模型。方法條目說明前提和停止條件，不能拿案例中的 gain、flux 或等待時間直接操作設備。

共享方式由使用者管理。使用者可以讓不同工作 repo 的 measure_knowledge 入口指向這個目錄，共享 symlink 不提供並行寫入隔離。
